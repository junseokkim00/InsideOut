# Inside Out: Emotional-driven dialogue generation via MAD

```bash
$ conda create -n insideout python=3.10
$ conda activate insideout
$ conda install ipykernel
$ pip install -r requirements.txt
```

## 🔥 Quick Start

1. generate `.env` with the template of `.env.example`
2. add `OPENAI_API_KEY`
3. run `insideout.sh` for demo experience
